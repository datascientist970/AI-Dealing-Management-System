# AI Dealing Management System

> A Django CRM for sales leads that combines AI lead analysis and AI-generated messages with free WhatsApp automation — import leads, let AI analyse and message them, and track everything from one dashboard.

## Overview

The AI Dealing Management System helps businesses manage leads end-to-end: leads are imported in bulk (Excel/CSV, including Apollo.io-style exports), the AI helper analyses each lead and drafts a personalized outreach message, and messages are sent over WhatsApp using the free automation path (PyWhatKit / Selenium — no paid Twilio account required). Sending progress, retries, interactions, and daily reports are all tracked inside the system.

## Key Features

- **Lead management** — add, edit, view, and organize leads (`core` app: leads list/detail/add/edit pages)
- **Bulk import with live progress** — Excel/CSV import (`import_progress.py`) with a real-time progress page
- **AI lead analysis** — leads store `ai_analysis` and `ai_message` fields generated by the AI helpers (`ai_helper.py`, `ai_message_generator_free.py`)
- **WhatsApp automation (free)** — bulk AI messaging UI, WhatsApp setup and confirmation flows (`whatsapp_free.py`), built on PyWhatKit + Selenium
- **Auto-processing** — `auto_processor.py` can automatically analyse and message newly added leads, with a dedicated "process pending" queue
- **Retry handling** — retry page for failed messages and a session checker (`session_checker.py`)
- **Interaction tracking** — log follow-ups/interactions per lead
- **AI insights & daily reports** — insights dashboard and daily performance reports, with Excel export
- **Authentication** — built-in login flow for the dashboard

## Getting Started

```bash
git clone https://github.com/datascientist970/AI-Dealing-Management-System.git
cd AI-Dealing-Management-System/dealing_system

python -m venv venv
venv\Scripts\activate        # Windows  (use source venv/bin/activate on Linux/macOS)

pip install Django>=5.2 pandas openpyxl pywhatkit==5.4 selenium webdriver-manager
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

## Usage

1. Log in at http://127.0.0.1:8000/login/
2. Add leads manually or import an Excel/CSV file and watch the import-progress page.
3. Open a lead to see its AI analysis and generated message, or use the AI bulk-messaging page to message many leads at once.
4. Complete the WhatsApp setup flow once (scan the WhatsApp Web QR code when prompted), then send, track, and retry messages from the dashboard.
5. Review daily reports and the AI insights page to measure outreach performance.

> WhatsApp automation works through WhatsApp Web — keep the browser session active while sending, and use the feature responsibly in line with WhatsApp's policies.
